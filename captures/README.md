# Captures

This directory contains the packet capture used for the NGAP/N2 analysis.

- `ngap_capture.pcap.pcap` — captured NGAP/SCTP traffic from the Open5GS + UERANSIM experiment.

Open the capture with Wireshark and apply the display filter:

```text
ngap
```

The capture is an academic lab artifact and should be treated as experimental evidence rather than a production-network trace.
